Como ler os comandos

O texto rian@ubuntu:~$ é o prompt: ele já aparece no terminal, não digite. Digite só o que vem depois e aperte Enter. O Linux diferencia maiúsculas de minúsculas. Para abrir o terminal no Ubuntu: Ctrl+Alt+T. Para colar um comando no terminal use Ctrl+Shift+V (o Ctrl+V não funciona ali). Dica extra: Tab completa nomes e ↑ repete o comando anterior.

passo 1Atualizar o sistema

Antes de instalar qualquer coisa, baixe a lista atual de pacotes e aplique as atualizações pendentes. Isso evita instalar versões antigas ou com falhas conhecidas.

sudo apt update
sudo apt upgrade -y
sudo
executa o comando como administrador (root). Pede a sua senha.
apt
gerenciador de pacotes do Ubuntu e do Debian.
update
só atualiza a lista de pacotes disponíveis. Não instala nada.
upgrade
instala as versões novas dos pacotes que você já tem.
-y
responde "sim" automaticamente à pergunta Continue? [Y/n]. Sem ele, digite Y e Enter.
A senha não aparece enquanto você digita

Nem asteriscos. É normal: digite a senha às cegas e aperte Enter. A atualização pode levar vários minutos; não feche o terminal. Se aparecer Could not get lock, outra atualização está rodando: aguarde e tente de novo.

passo 2Instalar o Apache2

O pacote apache2 instala o servidor web e as dependências (como apache2-bin, apache2-data e apache2-utils). O apt resolve tudo sozinho. No Ubuntu o serviço já inicia ao final da instalação.

sudo apt install apache2 -y

passo 3Verificar o status do serviço

O systemctl controla os serviços do Linux. O subcomando status mostra se o Apache está de pé.

sudo systemctl status apache2
Como sair dessa tela: aperte q

O terminal parece travado porque a saída abriu em um leitor (pager) e o prompt só volta quando você sai. Aperte q. Outros comandos do leitor: Espaço próxima página, b página anterior, ↑ ↓ rolar, ← → ver o final das linhas cortadas (o símbolo > na borda indica texto escondido) e / para buscar.

Quero o resultado direto no terminal

Use sudo systemctl status apache2 --no-pager. Ele imprime tudo e devolve o prompt sem abrir o leitor.

passo 4Habilitar na inicialização

O enable faz o Apache subir sozinho toda vez que a máquina liga. O start liga o serviço agora. São coisas diferentes: um age no próximo boot, o outro no momento atual.

sudo systemctl enable apache2
Synchronizing state of apache2.service with SysV service script with /usr/lib/systemd/systemd-sysv-install. Executing: /usr/lib/systemd/systemd-sysv-install enable apache2
ComandoEfeito
sudo systemctl start apache2liga agora
sudo systemctl stop apache2desliga agora
sudo systemctl restart apache2desliga e liga (derruba conexões)
sudo systemctl reload apache2relê a configuração sem derrubar conexões
sudo systemctl disable apache2não inicia mais no boot
systemctl is-enabled apache2responde enabled ou disabled

passo 5Descobrir o endereço IP

Para abrir o servidor no navegador você precisa do IP da máquina.

hostname -I
192.168.15.8 2804:...:fa0f

Veja o resultado na fig.03. O primeiro valor (192.168.15.8) é o IPv4, o que você vai usar. O segundo é o IPv6. O -I precisa ser maiúsculo: o -i faz outra coisa. Alternativa mais detalhada: ip -br -4 addr.

Outro computador não acessa a VM?

No VirtualBox, a placa de rede da VM precisa estar em Placa em modo bridge (Configurações, Rede). No modo NAT a VM ganha um IP interno (como 10.0.2.15) que a rede não enxerga.

passo 6Configurar o firewall (UFW)

O UFW é o firewall simples do Ubuntu: decide quais portas aceitam conexão. O Apache usa a porta 80. O Ubuntu já traz perfis prontos; o perfil Apache libera a 80.

sudo ufw allow 'Apache'
sudo ufw status
Para ativar o firewall com segurança

Se você administra o servidor por SSH, libere o SSH antes, senão perde o acesso: sudo ufw allow OpenSSH. Depois: sudo ufw enable e confira com sudo ufw status numbered. Perfis disponíveis: sudo ufw app list (Apache = porta 80, Apache Secure = 443, Apache Full = as duas).

passo 7Testar no navegador

Abra o Firefox e digite o IP na barra de endereço. De dentro da própria VM também funciona http://localhost.

http://192.168.15.8

Teste também pelo terminal: curl -I http://localhost deve responder HTTP/1.1 200 OK (se faltar o curl: sudo apt install curl).

passo 8Editar a página com o nano

O nano é um editor de texto de terminal. Usamos sudo porque a pasta /var/www/html pertence ao administrador; sem ele o nano abre o arquivo mas não consegue salvar.

sudo cp /var/www/html/index.html /var/www/html/index.html.bkp

O comando acima (recomendado) cria um backup da página original: cp origem destino. Agora abra o arquivo:

sudo nano /var/www/html/index.html

Apagar o conteúdo antigo

  • Selecionar várias linhas: segure Shift+Ctrl e aperte ↓ até marcar tudo. Depois Ctrl+K recorta o que está selecionado.
  • Sem seleção: Ctrl+K recorta a linha atual. Segure a tecla para repetir até esvaziar o arquivo.
  • Tudo de uma vez: Alt+\ (início do arquivo), Alt+A (inicia a seleção), Alt+/ (fim do arquivo) e Ctrl+K.
  • O mouse não move o cursor: use as setas. Errou? Alt+U desfaz.

Digitar o novo conteúdo

Digite ou cole com Ctrl+Shift+V:

<!DOCTYPE html> <html lang="pt-br"> <head> <meta charset="UTF-8"> <title>Meu Servidor Apache</title> </head> <body> <h1>Servidor Apache2 funcionando!</h1> <p>Configurado por Rian Lucas.</p> </body> </html>
<!DOCTYPE html>
declara que é um documento HTML5.
<html lang>
raiz da página; pt-br define o idioma.
<meta charset>
codificação UTF-8, para os acentos saírem certos.
<title>
texto da aba do navegador.
<h1> e <p>
título principal e parágrafo, dentro do <body>, que é o que aparece na tela.

Salvar e fechar

  1. Ctrl+O (Write Out) salva. O nano pergunta File Name to Write.
  2. Enter confirma o nome. Aparece algo como [ Wrote 11 lines ] e o * some.
  3. Ctrl+X fecha o nano.
Esqueceu de salvar?

Ao apertar Ctrl+X com alterações pendentes, o nano pergunta Save modified buffer?. Y salva (depois Enter), N sai sem salvar e Ctrl+C cancela. Se o Alt não responder no seu terminal, aperte Esc, solte, e depois a tecla. Para voltar à página original: sudo cp /var/www/html/index.html.bkp /var/www/html/index.html.

passo 9Conferir o resultado

Não precisa reiniciar o Apache: ele lê o arquivo do disco a cada acesso. Volte ao navegador e recarregue com F5. Se ainda aparecer a página antiga, Ctrl+F5 ignora o cache.

passo 10 (opcional)Ler os logs

Cada acesso ao site fica registrado. O tail mostra o fim de um arquivo.

sudo tail -n 10 /var/log/apache2/access.log
sudo tail -f /var/log/apache2/error.log

O primeiro mostra as últimas 10 linhas de acessos: IP de quem visitou, data, a requisição (GET / HTTP/1.1), o código de resposta (200 = ok, 304 = não mudou, 404 = não encontrado, 403 = proibido) e o navegador usado. O -f do segundo acompanha o arquivo ao vivo; saia com Ctrl+C.

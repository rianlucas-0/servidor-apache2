Servidor Apache2 no Ubuntu

Documentação técnica do passo a passo para instalar, verificar e personalizar um servidor web Apache2 em uma máquina virtual Ubuntu, do primeiro apt update até a página personalizada no navegador.

sistemaUbuntu (VirtualBox)
servidorApache/2.4.66
ip192.168.15.13
raiz web/var/www/html

1. Atualizar o índice de pacotes

Antes de instalar qualquer coisa, o apt precisa baixar a lista mais recente de pacotes dos repositórios. O sudo pede a senha do usuário. Ao final, o terminal informa quantos pacotes podem ser atualizados (442 neste caso).

sudo apt update
O que é o sudo?

O sudo executa o comando com permissões de administrador. Ao digitar a senha, o terminal pode não mostrar nada (ou só asteriscos). Isso é normal: continue digitando e aperte Enter.

update x upgrade

O apt update só atualiza a lista de pacotes disponíveis. Ele não instala nada. Quem instala as novas versões é o apt upgrade, no próximo passo.

2. Atualizar os pacotes instalados

O apt upgrade aplica as atualizações pendentes. Ele mostra o resumo (pacotes a atualizar e espaço necessário) e pergunta Continue? [Y/n]. Responda Y para confirmar.

sudo apt upgrade
Como responder o Y/n?

Digite Y e aperte Enter para continuar, ou N para cancelar. A letra maiúscula (Y) indica a resposta padrão: apertar só Enter também confirma. Essa etapa pode demorar vários minutos.

Se ficar travado?

Não feche o terminal durante a atualização. Para cancelar um comando em andamento, use Ctrl+C.

3. Instalar o Apache2

O pacote apache2 instala o servidor web e suas dependências (apache2-bin, apache2-utils, apache2-data e bibliotecas APR). No Ubuntu, o serviço já é habilitado ao final da instalação.

sudo apt install apache2
Dependências

São pacotes extras que o Apache precisa para funcionar. O apt resolve e instala tudo automaticamente.

4. Conferir a versão instalada

Confirma que o binário está disponível e mostra a versão. Aqui o resultado foi Apache/2.4.66 (Ubuntu).

apache2 -v
A opção -v

O -v (version) é uma opção que pede para o programa mostrar a versão e encerrar. Muitos comandos Linux aceitam essa opção.

5. Verificar o status do serviço

O systemctl status mostra se o serviço está ativo. O indicador verde e o texto active (running) confirmam que o Apache está rodando.

systemctl status apache2
Como sair da tela de status

O systemctl status abre a saída em um leitor de texto (pager). Repare no rodapé do print 11: lines 1-14/14 (END). O prompt só volta quando você sai dessa tela. Aperte q para sair, ou Ctrl+C.

Como ler o resultado

A bolinha verde e active (running) indicam que o serviço está rodando. enabled significa que ele inicia junto com o sistema. Se aparecer inactive (dead) ou failed, o serviço está parado.

6. Habilitar e iniciar no boot

O enable garante que o Apache suba automaticamente a cada inicialização. O start inicia o serviço agora, caso ele esteja parado.

sudo systemctl enable apache2
sudo systemctl start apache2
enable x start

enable controla o que acontece no próximo boot. start age agora. Para parar o serviço, use sudo systemctl stop apache2; para reiniciar, sudo systemctl restart apache2.

A mensagem do SysV

A linha Synchronizing state of apache2.service with SysV... é só informativa: o sistema está sincronizando o serviço com o mecanismo de compatibilidade. Não é erro.

7. Descobrir o endereço IP

O hostname -I lista os endereços IP da máquina. O primeiro, 192.168.15.13, é o IPv4 usado para acessar o servidor na rede local.

hostname -I
Por que o I maiúsculo?

No Linux, maiúsculas e minúsculas fazem diferença. O -I mostra os IPs da máquina; o -i faz outra coisa. A saída traz o IPv4 (192.168.15.13) e o IPv6 logo depois.

Acesso de outro computador

Esse IP é da rede local. Outro computador só acessa o servidor se estiver na mesma rede e, no VirtualBox, se a placa de rede da VM estiver configurada em modo Bridge.

8. Testar no navegador

Abra o Firefox e acesse o IP da máquina. A página padrão Apache2 Ubuntu Default Page com a mensagem It works! confirma que o servidor está respondendo.

Sem o https

O navegador mostra Not Secure porque o servidor responde em HTTP puro (porta 80), sem certificado. Para um teste em rede local isso é esperado.

9. Verificar e ativar o firewall (UFW)

Primeiro o status do UFW foi consultado: estava inactive. Em seguida o firewall foi ativado e a lista numerada de regras foi consultada.

sudo ufw status verbose
sudo ufw enable
sudo ufw status numbered

Observação: nos prints o UFW foi ativado sem nenhuma regra para o Apache. Para liberar acesso de outras máquinas da rede à porta 80, use sudo ufw allow 'Apache'.

O que é o UFW?

O UFW (Uncomplicated Firewall) é o firewall padrão do Ubuntu. Ele controla quais portas aceitam conexões. O Apache usa a porta 80 (HTTP).

Como ler o status

Status: inactive significa firewall desligado; Status: active significa ligado. O numbered lista as regras com números, o que facilita removê-las depois com sudo ufw delete NÚMERO.

10. Fazer backup da página padrão

Antes de editar, copie o index.html original. O backup index.html.bkp permite voltar atrás se algo der errado.

sudo cp /var/www/html/index.html /var/www/html/index.html.bkp
Como funciona o cp

A estrutura é cp origem destino. O sufixo .bkp é só uma convenção para marcar que é um backup. Para restaurar: sudo cp /var/www/html/index.html.bkp /var/www/html/index.html.

11. Editar a página inicial

O arquivo /var/www/html/index.html é a página servida pelo Apache. No nano, o conteúdo original foi apagado e substituído por um título simples.

sudo nano /var/www/html/index.html
<h1>Servidor do Rian com Apache2</h1>
Como salvar e fechar o nano

Os atalhos aparecem no rodapé do editor (o ^ significa Ctrl). Siga esta ordem: Ctrl+O (Write Out) para salvar, Enter para confirmar o nome do arquivo e Ctrl+X para fechar. O asterisco no título (index.html *, print 24) indica alterações ainda não salvas.

Se esquecer de salvar

Ao apertar Ctrl+X com alterações pendentes, o nano pergunta Save modified buffer?. Responda Y para salvar e depois Enter, ou N para sair sem salvar.

Apagar o conteúdo antigo

Para remover linhas, use Ctrl+K, que recorta a linha atual. Repita até esvaziar o arquivo. O mouse não move o cursor no nano: use as setas do teclado.

Não precisa reiniciar o Apache

O Apache lê o arquivo a cada acesso. Salvou, é só recarregar a página no navegador com F5.

12. Resultado final

Ao recarregar http://192.168.15.13 o navegador exibe a página personalizada, servida pelo Apache2 rodando no Ubuntu.

Algo deu errado?

Se a página não mudar, tente Ctrl+F5 para ignorar o cache. Se o Apache não responder, confira systemctl status apache2. Os logs de erro ficam em /var/log/apache2/error.log.
